Koppel Spotify

Log in met het Spotify-account (Premium) waarmee je de muziek afspeelt. Je wachtwoord gaat alleen naar Spotify zelf.

  1. Maak (met een Spotify Premium-account) een app aan op developer.spotify.com/dashboard. Kies bij "Which API/SDKs" zowel Web API als Web Playback SDK.
  2. Zet bij Redirect URIs precies deze link:
  3. Plak hier het Client ID van die app:
  4. Log in met het Spotify-account dat de muziek afspeelt. Staat dat account niet op jouw app, voeg het dan toe onder User management.

Je wachtwoord gaat alleen naar Spotify zelf. Alleen de spelleider logt in; de deelnemers hoeven niets.

Kies jullie playlist

Delen → Link naar playlist kopiëren. Spotify geeft in dit type app alleen de nummers van playlists die van jou zijn of waar jij medewerker van bent.

Lukt de playlist niet? Plak dan zelf de liedjes

Eén liedje per regel in de vorm Titel - Artiest. De app zoekt ze zelf op in Spotify.

Kies je stopmomenten

Kies per liedje na welke regel het liedje pauzeert. Laat je het op 🎲 staan, dan kiest de app zelf een moment. Met 🎧 Beluister hoor je het stuk vóór de stop. Let op: dit scherm laat de tekstregels zien, kijk dus niet mee als deelnemers meekijken.
